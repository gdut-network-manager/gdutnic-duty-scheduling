# 值班排班与签到系统 · 功能说明

本文按浏览器里看到的界面，逐页列出系统目前能做的事：每个功能在哪里、做什么、有多重要。内容依据当前工作区 2026-11-14 的实现整理。

系统有两个入口：

- **成员端**：`http://服务器地址:50025/`，值班成员查看排班、签到、登记外勤。
- **管理端**：`http://服务器地址:50025/<8 位随机路径>`，路径在服务启动时打印在控制台，管理员在这里维护排班、账号和设置。

重要程度分三级：

| 级别 | 含义 |
| --- | --- |
| 核心 | 排班、签到、考勤主流程的一部分，缺了系统无法正常使用 |
| 重要 | 日常管理经常用到，或者关系到账号安全和数据正确 |
| 辅助 | 改善体验或偶尔才用 |

## 2. 成员端

### 2.1 登录页

位置：打开 `/`，未登录时显示。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 姓名 / 学号密码登录 | 核心 | 输入姓名或已设置的学号，以及密码登录。新账号的初始密码是 `gg2017`，登录后可自行修改。同一真实账号失败 50 次后暂停 5 分钟，姓名和学号共用限额；其他账号不受这项计数影响。来源失败过多时会限制失败请求，但不会因共享代理而阻断其他账号的正确登录。 |
| 通过 GDUTNIC 登录 | 重要 | 管理员在「其他设置 → SSO 设置」启用后，登录框出现「通过GDUTNIC」按钮，跳转到统一身份认证。首次使用需要先绑定本地账号（见第 3 节）。 |
| 密码显示 / 隐藏 | 辅助 | 点密码框右侧的眼睛图标即时切换明文和密文，仅图标做左上到右下及反向过渡，输入内容和光标保留。 |

如果系统还没有创建原始管理员，打开 `/` 会自动跳到管理端的首次设置页。

### 2.2 侧栏

位置：登录后页面左侧。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 页面导航 | 核心 | 「概览」始终显示；「排班列表」「外勤确认」只在所属权限组开放了对应权限时出现。 |
| 手机上的导航抽屉 | 辅助 | 窗口宽度不超过 800px 时侧栏收起，页面顶部出现顶栏：左侧菜单按钮，旁边显示当前页面名称。点菜单按钮从左侧滑出侧栏；选择页面、点侧栏外的遮罩或按 Esc 关闭。 |
| 主题切换 | 辅助 | 「网络服务协会」右侧的圆形按钮，太阳表示当前浅色、月亮表示当前深色。页面默认跟随系统主题；手动切换只对当前页面有效，刷新后重新跟随系统。点击时新主题从按钮中心向外扩散，未覆盖区域保留旧画面；过渡结束后清理临时动画与快照引用。 |
| 修改密码 | 重要 | 侧栏底部「修改密码」。需输入当前密码和至少 6 位的新密码，修改后长期有效。 |
| 退出登录 | 重要 | 侧栏底部「退出登录」，立即注销当前设备的登录。 |

### 2.3 概览

位置：成员端 → 侧栏「概览」。顶部显示「某某，欢迎回来」。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 当日排班时间轴 | 重要 | 「当日排班」下方的横向时间轴，标出当前时间、本人当天各班次的起止和同班人员。右上角「刷新」重新读取。 |
| 外勤登记 | 核心 | 时间轴下方的「外勤登记」卡片，显示本月已完成次数。按钮有三个状态：`点击登记` →（点击后）`等待确认`（黄色）→（在「外勤确认」页被确认后）`登记完成`（绿色，锁定）。点击只会进入等待确认，不会自动完成。没有「外勤」权限时按钮显示「暂无外勤权限」；当前网络不在允许范围时显示「当前网络不可用」。 |
| 本人班次卡片 | 核心 | 只列出本人当天的班次。每张卡片显示起止时间、备注、「已签到人数 / 总人数」，以及同班每个人的状态：待签到、已签到、已签到（待确认）、旷班；迟到和旷班用颜色区分。 |
| 确认签到 | 核心 | 班次卡片里的「确认签到」按钮。从班次开始前的「提前打卡」分钟数起可以点击，窗口外显示「未在签到时间内」。签到后记录到岗时间并显示「已签到」。如果下一班与本班首尾相接（第 1→2 班、第 3→4 班），会一并签到。没有「打卡」权限或网络不符合要求时按钮置灰并说明原因。 |

### 2.4 排班列表

位置：成员端 → 侧栏「排班列表」。需要「排班列表」权限，默认会员组不开放。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 按周浏览全员排班 | 重要 | 以周历形式显示所有人已生成的排班和完整姓名，可点「上一周」「下一周」「回到本周」。这里只看排班，不显示任何人的考勤状态。 |

### 2.5 外勤确认

位置：成员端 → 侧栏「外勤确认」。需要「外勤确认」权限。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 确认外勤登记 | 核心 | 列出本月所有处于「等待确认」的登记和登记时间，包括本人的。点「点击确认」后该登记变为已完成并计入统计，卡片随后消失。系统不限制确认人，有此权限的成员也能确认自己的登记。 |
| 删除外勤登记 | 重要 | 点「删除」并确认后，该登记回到未登记状态，对方可以重新登记。 |
| 刷新 | 辅助 | 右上角「刷新」重新读取待确认列表。 |

外勤登记必须由其他成员确认：待确认列表不显示本人记录，直接调用本人确认接口也会被拒绝。管理员在「外勤管理」中的改判仍按原权限执行。

## 3. SSO 绑定页

位置：通过 GDUTNIC 登录后，系统找不到对应的本地账号时自动跳转到 `/auth/keycloak/bind`。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 绑定本地账号 | 重要 | 页面显示当前 SSO 账号，输入已有本地账号的用户名和密码后点「验证并绑定」。绑定一次后，以后可直接用 GDUTNIC 登录。 |
| 自动匹配确认 | 辅助 | 管理员开启了自动匹配且找到同名的普通成员账号时，弹出「是否将 A 绑定到 B」的确认框。管理员账号和原始管理员不会自动匹配，必须输入本地密码。 |
| 返回登录 | 辅助 | 放弃绑定，回到登录页。 |

## 4. 管理端

侧栏的每个页面对应一项权限，账号所属的权限组没有开放的页面不会出现在侧栏里，直接调用也会被服务器拒绝。原始管理员固定拥有全部权限。

### 4.1 首次设置与登录页

位置：打开管理端网址，未登录时显示。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 创建原始管理员 | 核心 | 系统第一次打开时显示。可以自定义名称（留空则叫「原始管理员」），密码至少 6 位。只能创建一次。 |
| 管理员登录 | 核心 | 用户名或学号和密码登录。只有至少拥有一项管理端权限的账号才能进入。按来源和账号分别计数，10 分钟内失败 8 次后暂停 10 分钟。 |
| 通过 GDUTNIC 登录 | 重要 | 启用 SSO 后出现，流程同成员端。 |

### 4.2 侧栏

位置：登录管理端后页面左侧。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 页面导航 | 核心 | 依次为：概览、每周排班、特殊排班、调换值班、外勤管理、用户管理、权限组管理、消息推送、查看日志、数据管理、其他设置、关于与帮助。只显示有权限的项。 |
| 手机上的导航抽屉 | 辅助 | 与成员端相同。导航项较多时在抽屉内上下滚动，「退出登录」固定在抽屉底部。 |
| 主题切换 | 辅助 | 与成员端相同。 |
| 退出登录 | 重要 | 侧栏底部，注销当前设备的管理端登录。 |

### 4.3 概览

位置：管理端 → 侧栏「概览」。需要「查看概览」权限；改判考勤另需「更改考勤状态」。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 本月出勤统计 | 重要 | 页面顶部三个药丸：本月出勤率（正常 / 总出勤）、本月迟到数、本月旷班数。右侧圆形按钮刷新整页。 |
| 当前值班时间轴 | 重要 | 「当前值班」下方的时间轴，显示此刻和前后的班次及值班人员。 |
| 周排班周历 | 核心 | 按周一到周日显示第一至第四班，缺班留空；该周有特殊排班时在下方多出一行。标题两侧的箭头翻到上一周 / 下一周，范围是有排班的最早到最晚一周；离开本周后出现「回到本周」。 |
| 班次详情 | 核心 | 点击周历里的班次卡片，弹窗显示该班的时间、备注和每个人的考勤状态（正常、迟到、旷班、待签到、待确认）。 |
| 考勤改判 | 核心 | 在班次详情里点某个人名，通过带图标的连体单选按钮组改为准时、迟到或旷班；未签到的人也可以改判。没有「更改考勤状态」权限时人名只是文字，不能点。 |
| 删除整周排班 | 重要 | 「删除本周排班」删除当前显示这一周的全部班次，需输入确认语「删除本周排班」。已签到和已确认的考勤先归档，统计里仍能查到；每周固定排班表和账号不受影响。 |
| 异常统计 | 重要 | 周历下方，可切换「近 2 周」「近 4 周」。左右两栏用横向柱状图分别列出每个人的迟到次数和旷班次数。 |

管理端目前没有修改单个普通班次的入口。要调整某一天的普通班次，可以重新生成排班，或在「数据管理 → 班次 / 考勤人员」里修改。

### 4.4 每周排班

位置：管理端 → 侧栏「每周排班」。需要「每周排班」权限。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 班次时间 | 核心 | 页面顶部填写四个班次各自的开始和结束时间。 |
| 每周固定排班表 | 核心 | 班次 × 周一至周日的表格，每格一行填一位人员姓名。这是模板，本身不产生班次。 |
| CSV 模板下载 | 重要 | 「下载 CSV 模板」得到一份表头为星期、首列为班次的表格，多人用「/」分隔。 |
| 一键导入 | 重要 | 「一键导入」选择填好的 CSV，把人员填进表格，导入后仍需核对并保存。 |
| 保存每周排班 | 核心 | 需先勾选「我已核对人员姓名」。保存时会为表里尚无账号的人员创建账号（初始密码 `gg2017`）。 |
| 补全用户 | 重要 | 按已保存的每周表和所有已生成的排班（含特殊排班）补建缺失的账号，已有账号的密码不变。 |
| 生成排班 | 核心 | 选择开始和结束日期（开始不能早于今天），按星期把模板展开成具体班次。区间内已有或时间冲突的班次，无人签到时被覆盖，有人签到时跳过。 |
| 清除所有排班 | 重要 | 删除所有日期的班次和签到，需输入确认语「清除所有排班」。已有的考勤结果会归档保留；每周固定排班表和账号保留。 |

### 4.5 特殊排班

位置：管理端 → 侧栏「特殊排班」。需要「特殊排班」权限。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |
| 新增特殊排班 | 重要 | 「新增特殊排班」弹窗填写日期、开始和结束时间、值班人员（每行一位）和备注。结束时间早于开始时间表示次日结束。 |
| 编辑 / 删除 | 重要 | 「未来特殊排班」列表里每张卡片有「编辑」和「删除」；删除前弹出页面内的居中确认卡片，确认后连同该班签到记录删除；取消不会提交。 |
| 未来特殊班次统计 | 辅助 | 页面上方两个药丸：未来特殊班次数、排班人次。「刷新」重新读取。 |

### 4.6 调换值班

位置：管理端 → 侧栏「调换值班」。需要「调换值班」权限。

| 功能 | 重要程度 | 说明 |
| --- | --- | --- |

## 5. 没有独立入口的自动行为

位置：没有独立入口，由系统在后台自动执行。

这些功能不对应某个按钮，但会影响各页面上看到的结果。

| 行为 | 重要程度 | 说明 |
| --- | --- | --- |
| 考勤自动判定 | 核心 | 签到时立即按「值班时间」的设置判定正常、迟到或旷班并保存。超过旷班时间仍未签到的人，由后台定期记为旷班。之后修改设置不会改变已保存的结果。 |
| 连班自动签到 | 核心 | 第 1 班与第 2 班、第 3 班与第 4 班首尾相接时，签到前一班会把后一班一并签到。 |
| 实时同步 | 重要 | 有人签到或管理员改判考勤后，打开着成员概览或管理端概览的页面会自动刷新变化的卡片、人数、统计和时间轴，不需要手动刷新。 |
| 登录自动失效 | 重要 | 超过无操作时限或无响应时限的登录自动退出。改密码、停用账号、解除 SSO 绑定会让相关登录立即失效。 |
| 定时邮件推送 | 重要 | 服务运行期间按「消息推送」的计划在周日发信。停机错过多次时只补发最近一个到期的完整周期；发送失败 15 分钟后重试，已成功的邮箱不重复发送。 |
| 调班记录自动清理 | 辅助 | 双方都签到且两个班次都结束后，调班记录自动消失。 |
| 启动时补齐账号 | 辅助 | 每次启动服务，为每周固定排班表和已排班人员补建缺失的账号。 |
| 存储容量上限 | 辅助 | 操作日志超过 10 MB 时删到 5 MB 以下。出勤归档、外勤记录、调班、推送发送记录、SSO 绑定这五张表各自超过 10 MB 时删到 7 MB 以下，都是先删最旧的记录。 |
